** Repository path
#+name: testament-path
#+begin_src elisp :var path="" :results verbatim
  (expand-file-name path (project-root (project-current t)))
#+end_src

Canonical path to repository root, with an optional =path= argument.  Examples:

#+begin_example
  <<testament-path()>>
  => "/path/to/repository"

  <<testament-path("my/file")>>
  => "/path/to/repository/my/file"
#+end_example
