Source code of Emacs is optional.  It will be used for displaying source of C
functions.

In Guix, =doc= output of the Emacs package stores source code under the
=c-source= directory, differing from =src= expected by =helpful--library-path=.
Advise the function.

#+begin_src elisp :noweb-ref emacs-init
  (use-package helpful
    :config
    (defun hako/helpful--library-path-advice (library-name)
      (when (member (f-ext library-name) '("c" "rs"))
        (setq library-name
              (f-expand (f-filename library-name)
                        find-function-C-source-directory)))
      (condition-case nil
          (find-library-name library-name)
        (error nil)))
    (advice-add #'helpful--library-path :override #'hako/helpful--library-path-advice)
    :bind
    ([remap describe-function] . helpful-callable)
    ([remap describe-variable] . helpful-variable)
    ([remap describe-key]      . helpful-key)
    ([remap describe-command]  . helpful-command)
    ([remap describe-symbol]   . helpful-symbol)
    ("C-c C-d" . helpful-at-point))
#+end_src

Xref stops searching if one backend fails to find the symbol.  Replace it with
Citre since the latter supports [[https://github.com/universal-ctags/citre/blob/master/docs/user-manual/adapt-an-existing-xref-backend.md][adapting existing Xref backends]] and handles

#+begin_src elisp :noweb-ref emacs-init
  (use-package citre
    :custom
    (citre-default-create-tags-file-location 'global-cache)
    (citre-edit-ctags-options-manually nil)
    (citre-find-definition-backends
     '(eglot elisp geiser tags dumb-jump))
    (citre-find-reference-backends
     '(eglot elisp dumb-jump))
    :bind
    ([remap xref-find-definitions] . citre-jump)
    ([remap xref-find-references]  . citre-jump-to-reference)
    ([remap xref-go-back]          . citre-jump-back)
    ("C-x c p" . citre-ace-peek)
    ("C-x c u" . citre-update-this-tags-file))

  (use-package citre-config)
#+end_src

Citre has builtin support for Eglot.  Other backends will be converted later
in their own sections.

Elisp Xref backend doesn't handle =*.el.gz= files by itself and returns =*.el=
files instead in =elisp--xref-make-xref=.  Advise so that Citre can find the
files.

#+begin_src elisp :noweb-ref emacs-init
  (use-package elisp-mode
    :after citre
    :config
    (defun hako/elisp--xref-make-xref-advice (orig type symbol file &rest rest)
      (let ((file* (if (string-suffix-p ".el" file)
                       (find-library-name file)
                     file)))
        (apply orig type symbol file* rest)))
    (advice-add #'elisp--xref-make-xref :around #'hako/elisp--xref-make-xref-advice)

    (defvar citre-elisp-backend
      (citre-xref-backend-to-citre-backend
       'elisp
       (lambda () (derived-mode-p 'emacs-lisp-mode))))
    (citre-register-backend 'elisp citre-elisp-backend))
#+end_src
