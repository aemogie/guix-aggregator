Once downloaded, follow Guix System's [[https://guix.gnu.org/manual/devel/en/html_node/System-Installation.html][installation instructions]].

Comparing with the official one, these LiveCDs integrate Linux kernel and
nonfree firmwares from the [[https://gitlab.com/nonguix/nonguix][Nonguix channel]] to support more hardware.  The
experience should be the same as installing on hardware that supports
Linux-Libre.

To provide similiar downloading experience around the world, they are configured
to use [[https://guix.moe/][Guix Moe]]'s infrastructure.  It won't be available in the installed
system, so you'll need to set it up later if you want.

For manual installation, I suggest using the installer first to configure
locale, keyboard layout and networking, stopping at the step setting a password.

In the LiveCDs, [[https://fishshell.com/][fish]] is chosen as the login shell and several example
configurations are available under =/etc/configuration=.  These examples are
based on the ones shipped in Guix, with Nonguix channel configured.

Here follows ttys in the LiveCDs:
- tty1 (=Ctrl+Alt+F1=) :: Guix System installer.
- tty2 (=Ctrl+Alt+F2=) :: [[https://guix.gnu.org/manual/devel/en/][GNU Guix reference manual]].
- tty3~6 (=Ctrl+Alt+F3= ~ =Ctrl+Alt+F6=) :: =root= shell.
- tty7 (=Ctrl+Alt+F7=) :: Login manager (not included in the Minimal variant).
- tty12 (=Ctrl+Alt+F12=) :: System log.

For the login manager: it logs into a desktop environment built around the [[https://github.com/YaLTeR/niri][niri]]
Wayland compositor

Default keybindings:
+ =Super+Shift+/= :: Open an overlay for available hotkeys.
+ =Super+T= :: Open terminal emulator: [[https://codeberg.org/dnkl/foot][foot]].
+ =Super+D= :: Open application launcher: [[https://github.com/davatorium/rofi][rofi]].

Configurations files for the environment, including a pre-configured Emacs text
editor are [[https://codeberg.org/hako/Rosenthal/src/branch/trunk/modules/rosenthal/examples][managed in the Rosenthal channel]], exposed as =%rosenthal-skeletons=
and available under =/etc/skel= when configured.

A ~set-keymap~ script is provided for keyboard layout setup.  Since the
installer already does part of its work, you generally don't need it.

#+begin_example
  Usage: set-keymap LAYOUT [VARIANT] [-m MODEL] [-o OPTIONS]

  OPTIONS are comma-separated e.g. "ctrl:nocaps,grp:alt_shift_toggle"
#+end_example

Example usage below

#+begin_example
  $ set-keymap us dvorak -o ctrl:nocaps
#+end_example

For a full list of available layouts, variants, models and options, refer to the
[[https://man.archlinux.org/man/extra/xkeyboard-config/xkeyboard-config.7.en][xkeyboard-config.7]] manual page.
