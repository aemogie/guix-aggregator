Once downloaded, follow Guix System's [[https://guix.gnu.org/manual/devel/en/html_node/System-Installation.html][installation instructions]].

Comparing with the official one, these LiveCDs integrate Linux kernel and
non-free firmware from [[https://gitlab.com/nonguix/nonguix][Nonguix channel]] to support more hardware.  The process
should be the same as installing on hardware that supports Linux-Libre.

To provide similiar downloading experience around the world, they are configured
to use [[https://guix.moe/][Guix Moe]]'s infrastructure.  It won't be available in the installed
system, so you'll need to set it up later if you want.

After entering these LiveCDs, I suggest using the guided installer on tty1 first
to configure keyboard layout and networking.

For manual installation, [[https://fishshell.com/][fish]] is chosen as the login shell and several Guix
System configuration examples are available under =/etc/configuration=.  These
examples are based on the ones shipped in Guix, with Nonguix channel configured.

Here follows ttys in the LiveCDs:
- tty1 (=Ctrl+Alt+F1=) :: Guix System installer.
- tty2 (=Ctrl+Alt+F2=) :: [[https://guix.gnu.org/manual/devel/en/][GNU Guix reference manual]].
- tty3~6 (=Ctrl+Alt+F3= ~ =Ctrl+Alt+F6=) :: =root= shell.
- tty7 (=Ctrl+Alt+F7=) :: Login manager (not included in Minimal variants).
- tty12 (=Ctrl+Alt+F12=) :: System log.

The login manager on tty7 logs into a desktop environment built around [[https://github.com/YaLTeR/niri][niri]]
Wayland compositor and [[https://noctalia.dev/][Noctalia]] desktop shell.  It also starts Guix System
installer automatically and you can continue guided installation there.

Loading of the desktop environment may take quite a while, depending on read
performance of your installation media.  It will be much better when the system
is installed in the disk.

User name: =live=, password: =live=, in case you'll need them.

Default keybindings:
+ =Super+Shift+/= :: Open an overlay for available hotkeys.
+ =Super+D= :: Open application launcher.
+ =Super+Return= :: Open terminal emulator: [[https://wezterm.org/][WezTerm]].

Dotfiles for this environment, including a pre-configured Emacs text editor are
[[https://codeberg.org/hako/Rosenthal/src/branch/trunk/modules/rosenthal/examples][managed in the Rosenthal channel]], exposed as =%rosenthal-skeletons= and
available under =/etc/skel= when configured.
