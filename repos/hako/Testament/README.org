#+TITLE: Testament - Personal dot(?)files

This repository contains my dotfiles and Guix System literate configurations.

** Usage
Environment setup is done via [[https://guix.gnu.org/manual/devel/en/html_node/Invoking-guix-time_002dmachine.html][~guix time-machine~]] and [[https://guix.gnu.org/manual/devel/en/html_node/Invoking-guix-shell.html][~guix shell~]].  [[file:.envrc][.envrc]] is
available for [[https://direnv.net/][direnv]] to automate the process.

#+begin_example
  $ guix time-machine -C channels.lock -- shell -m manifest.scm
#+end_example

This repository uses [[https://codeberg.org/lapislazuli/blue][BLUE build system]], the entry point is at [[file:blueprint.scm][blueprint.scm]].

#+begin_example
  $ blue configure
  $ blue build
  $ blue help
#+end_example

** [[file:config/live][LiveCDs]]
I provide Guix System installation images in this repository, pre-built images
below.

Variants:
- Minimal: console-based installation, the installer runs on [[https://www.freedesktop.org/wiki/Software/kmscon/][kmscon]].
- Niri: start installation in a desktop environment built around [[https://github.com/YaLTeR/niri][niri]] Wayland
  compositor and [[https://noctalia.dev/][Noctalia]] desktop shell. (3D acceleration required)

Once downloaded, follow Guix System's [[https://guix.gnu.org/manual/devel/en/html_node/System-Installation.html][installation instructions]].  Loading of the
desktop environment may take quite a while, depending on the read performance of
your installation media.  It will be much better when the system is installed
on-disk.

Comparing with the official one, these images integrate Linux kernel and
non-free firmware from [[https://gitlab.com/nonguix/nonguix][Nonguix channel]] to support more hardware.  The process
should be the same as installing on hardware that supports Linux Libre.

To provide similiar downloading experience around the world, they are configured
to use [[https://guix.moe/][Guix Moe]]'s infrastructure.  It won't be available in the installed
system, so you'll need to set it up later if you want.

For manual installation, [[https://fishshell.com/][fish]] is chosen as the login shell and several Guix
System configuration examples are available under =/etc/configuration=.  These
examples are based on the ones shipped in Guix, with Nonguix channel configured.

For the desktop environment:

User name: =live=, password: =live=, in case you'll need them.

Dotfiles, including a pre-configured Emacs text editor, are [[https://codeberg.org/hako/Rosenthal/src/branch/trunk/modules/rosenthal/examples][managed in the
Rosenthal channel]], exposed as =%rosenthal-skeletons= and available under
=/etc/skel= when configured.
