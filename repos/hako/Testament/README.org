#+TITLE: Testament - Personal dot(?)files

This repository contains my dotfiles and Guix System literate configurations.
(README for [[file:config/live][LiveCDs]] has been moved to its own directory.)

** Usage
Environment setup is done via [[https://guix.gnu.org/manual/devel/en/html_node/Invoking-guix-time_002dmachine.html][~guix time-machine~]] and [[https://guix.gnu.org/manual/devel/en/html_node/Invoking-guix-shell.html][~guix shell~]].  [[file:.envrc][.envrc]] is
available for [[https://direnv.net/][direnv]] to automate the process.

#+begin_example
  $ guix time-machine -C channels.lock -- shell -m manifest.scm
#+end_example

This repository uses [[https://codeberg.org/lapislazuli/blue][BLUE build system]], the entry point is at [[file:blueprint.scm][blueprint.scm]].

#+begin_example
  $ blue configure
  $ blue build
#+end_example

For available commands, run ~blue help~.

#+begin_example
  $ blue help
#+end_example

Examples:

- Configure [[https://guix.gnu.org/manual/devel/en/html_node/Substitutes.html][substitute servers]]:

#+begin_example
  $ blue configure URL='https://bordeaux.guix.gnu.org https://ci.guix.gnu.org'
#+end_example

- Variables can also be set temporarily:

#+begin_example
  $ blue URL='https://cache-cdn.guix.moe' build-os
#+end_example

- Multiple commands can be chained by =--=, they'll be executed in order.

#+begin_example
  $ blue build -- compile -- build-os
#+end_example

** Systems
*** [[file:config/dorphine.org][dorphine]] (x86_64-linux, UEFI, ZFS, NVIDIA) | [[file:deploy/dorphine.scm][deploy]]
Notes on ZFS:
- support is currently implemented as =zfs-service-type= in [[https://codeberg.org/hako/Rosenthal][Rosenthal channel]]
- root on ZFS requires [[https://codeberg.org/hako/Rosenthal/src/branch/trunk/modules/rosenthal/packages/patches/guix-wip-zfs-boot-support.patch][a patch to Guix System]]
- I'm using use a customized kernel with ZFS module built in to avoid
  compatibility issue with Guix initrd.
- GRUB bootloader is not supported, it reports [[https://savannah.gnu.org/bugs/?47742][this error]] when booting from
  the ZFS dataset containing =/gnu/store= so I use Limine and unified kernel
  images instead.
- At least datasets containing =/gnu=, =/var/guix=, =/etc= (needed for boot) and
  =/home= (=account-service-type=) should be managed by Guix System.

Notes on NVIDIA proprietary driver:
- don't use GDM
